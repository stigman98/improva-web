# improva.es

Web de Improva. Cada cambio en `main` se publica solo en Netlify (proyecto **improvaes**).

- `index.html`: la web
- `404.html`: página de error
- `robots.txt`, `sitemap.xml`: para Google
- `llms.txt`: resumen de Improva para buscadores con IA (ChatGPT, Gemini, Perplexity)
- Páginas de servicio (SEO): `creacion-de-contenido-madrid/`, `edicion-de-video/`, `automatizaciones-con-ia/`, `herramientas-ia-a-medida/`, con estilos en `servicios.css` y logo en `img/improva.png`
